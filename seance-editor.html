🎛️ Редактор сеансу майданчика

Назва вистави — для глядача. Seance ID — технічний ключ. Сеанс, зал, розцінка та місця належать майданчику. Після публікації сеанс може бути переданий зовнішньому оператору через Gateway.

Перевірка доступу…

Сеанс

Завантаження існуючого сеансу або створення нового.

Розцінка переноситься тільки між сеансами одного залу. Вставлення не записує зміни в базу — спочатку перевірте схему, потім натисніть «Зберегти».

🧾 Дані сеансу

Назва події — для глядача. Seance ID — технічний ключ.
Чернетка доступна редактору та Content Studio, але не показується на сайті.
Публічний показ починається тільки після окремої публікації.
Зал завантажується…

➕ Правило по рядах

Для суцільних рядів. Наприклад: P1-3, P4-8.

🎨 Діапазон місць у рядах

Для випадків типу: ряд 7, місця 1–6 одна ціна/колір, 7–17 інша, 18–23 третя. Записується в seat_overrides автоматично.

🎭 Ложі вибраного залу

Ложі та їхні реальні ключі беруться зі схеми вибраного залу.
